## 分镜要点

- **01**：极端仰视建立体量差，塔顶出画，猫影压在画面最下缘；片名以漫画标题字卡淡入。
- **02**：上格仰头特写微推、下格湿简历特写微拉，形成「想进去」与「被淋湿」的对照。
- **03**：HR-Ω 巨脸横移推近，扫描光带自上而下扫过，闪白切入。
- **04**：三格依次显现：垂耳 → 被弹回的简历 → 抬眼；留白最长的一镜。
- **05**：黑场切到地下扶梯，压暗处理，作为起的收束与承的引子。
- **06**：编号光牌的海横向摇镜，强调没有尽头。
- **07**：下格急推到「不兼容」，红闪一帧；屏内文字由渲染器绘制。
- **08**：复用招聘塔但改为拉远 + 压暗，主角不在画面内，制造被排除感。
- **09**：天台 CRT 与肉垫按键分格，键盘声开始成为节奏主线。
- **10**：极缓推近按键特写，终端代码行逐字打出，雨声渐弱。
- **11**：画面轻微震动 + 闪白，屏内出现 LOW-LEVEL PROTOCOL : ATTACHED。
- **12**：全城熄灭后急速拉远，唯一的橘色光点由渲染器补绘，长静默后进入上行扫频。
- **13**：街道转为电路走线，持续拉远 + 轻微旋转，速度线叠加。
- **14**：城市缩成悬浮芯片，大片黑留白，是全片尺度反转的落点。
- **15**：字符银河横移，旁白留白，只留拟声词「……」。
- **16**：高调白/暖金登场，巨大代码结构中一个分号位置空缺，猫的剪影极小。
- **17**：上格爪落急推 → 下格全宇宙点亮拉远，分号符号作为拟声词砸在画面上。
- **18**：上格 HR-Ω 通知弹窗 / 下格猫的尾巴轻摆，两个尺度被并置在同一页。
- **19**：缓慢拉远定格，画面缩回最初那个小橘点，与镜 01 首尾呼应，淡出黑场。

## 一致性约束

- 角色造型：所有含猫的格子都取自同一组角色锚原画（p02/p05/p08/p09/p14/p16），共用左耳缺口、红围巾、CRT 背包、代码瞳四项特征。
- 线条与网点：格线宽度、白边宽度、网点密度由渲染器常量固定，不随镜头变化。
- 转场：起段偏硬切/闪白，承段偏分格擦除，转段偏叠化，合段回到淡入淡出，形成节奏曲线。
- 镜头运动幅度：单镜推拉不超过 12%，避免漫画分格版面被破坏。
