## 六、关键声音设计点

- **00:57 全城熄灭**：`blackout` 让所有铺底瞬间归零，留 0.4 秒绝对静默，再由 `riser` 上行扫频把「视野被拉到光年之外」听觉化。
- **承段**：机械键盘的 `keyboard` 节奏串取代 BGM 节拍，成为主角「一个键一个键」的动作主线。
- **合段**：`chime` 单音对应分号落下，`bloom` 暖金大三和弦对应宇宙重新点亮，随后撤掉所有铺底，只留一声键盘与静默收尾。
- 环境铺底（rain / hum / crowd / data / riser）按连续区间合并生成，避免相邻镜头叠加导致音量跳变。
